# z-ha-buttons

PWA mobile-first pour piloter des boutons Home Assistant.

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview:manual
```

Le serveur reste ouvert sur `4173` pour la vérification manuelle.

## Notes

- Application hors ligne.
- Base locale via Dexie.
- Secrets chiffrés via Web Crypto.
